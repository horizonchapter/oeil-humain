# Contribuer à oeil-humain

Les idées et corrections sont bienvenues.

1. Ouvre une **issue** (modèles fournis) pour décrire le problème ou l'idée.
2. Pour proposer un changement : fork, branche, modification, pull request.
3. Teste ta modification (installation, exemple, rendu) avant de proposer la pull request, et décris ce que tu as vérifié.
4. Garde le contenu **court** : chaque ligne doit changer le comportement de Claude.
5. Exemples toujours **fictifs** : aucune donnée réelle.
